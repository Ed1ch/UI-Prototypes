# Zanevka UI Prototypes

Публичная коллекция **автономных** интерактивных UX/UI-макетов Zanevka, не подключённых к рабочей почте или серверу.

## Макеты

- [AI Access Control — настройки доступа агента в `/my`](./ai-access-control/) — концепт для Zanevka MCP 3. Исходная спецификация: [issue #28](https://github.com/Ed1ch/zanevka-mcp-v2/issues/28) (ссылка может требовать доступ к приватному репозиторию).

## Как включить GitHub Pages

Repository **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save**.
